## 🗂️ Project

#### 🎥 [다보이조](https://github.com/VEDA-4-Final-Project/daboyijo) — 직접 만들어 본 미니 VMS
>
> ##### 간략소개 : 요양시설 낙상 감지 · 다채널 영상 관제 시스템. 웨어러블(STM32)과 CCTV 두 경로를 독립 운영해 낙상을 판정하고, 영상 수집부터 관제 클라이언트까지 VMS의 기능 축을 직접 구현했습니다.
>
> ##### 📆 기간 : 2026.07 ~ 2026.09 (9주) · 한화비전 VEDA 4기 최종 프로젝트, 🏅우수상 · 팀원 5명
>
> ##### 담당업무 : [서버/클라이언트] RTSP 파이프라인, 낙상 감지, 서버(C++) 및 Qt 관제 클라이언트, 텔레그램 알림 연동
>
> **기술적으로 파고든 지점**
> - 🎞️ **4채널 30fps 회복** — 17.6fps로 떨어진 원인이 큐 용량이 아니라 *채널을 순차 순회하던 단일 루프 구조* 자체임을 찾아내고 파이프라인을 재설계
> - 🧩 **수평 확장** — 보드당 수용 채널을 2로 산정해 RPi4 2대(2+2ch) 구조로 분리, 카메라 설정을 15→30fps 상향
> - 🤸 **낙상 감지** — MoveNet Thunder(int8) 기반, 어깨-엉덩이 벡터 각도 55° 임계값
> - ⚖️ **AND → OR 판정 전환** — 웨어러블 미착용·배터리 방전 시 낙상을 놓칠 수 없다는 판단으로 두 경로를 OR로 묶고, 5초 내 동일 사건은 `source=BOTH`로 통합해 중복 기록 해결
> - 🔌 **커스텀 TCP 프로토콜(0xDB4B)** 설계 — 엣지·서버 분리 구조
> - 🧠 **VLM 2-way 활용** — ① 낙상 확정 시 전후 버퍼 프레임을 VLM에 넘겨 상황 요약 후 텔레그램 통지 ② 자연어 질문("어제 낙상 있었어?")을 (사건 유형, 시간 범위)로 구조화해 이벤트 검색
> - 🕶️ **프라이버시 블러** — 상시 얼굴 흐림 처리, 낙상 발생 시에만 해당 인물만 원복
> - 📷 사용 장비 : 한화비전 PNM-C16083RVQ (4ch)
>
